ENDORSECRYPTO LOGO DESIGN PACK
==============================

Included brand lockups
----------------------
1. Logo 1 - Horizontal: primary website/header lockup.
2. Logo 2 - Portrait: vertical/narrow layout.
3. Logo 3 - Stacked: centered lockup for square-ish placements.
4. Icon 1 - Primary: standalone mark for favicons, PWA and app icons.

Folders
-------
Logo Files/Transparent/PNG  - transparent raster logos in Brand Blue, White and Black.
Logo Files/Transparent/SVG  - single-colour vector-traced SVG exports.
Logo Files/Transparent/PDF  - PDF equivalents of the transparent vector exports.
Logo Files/PNG and JPG      - ready-to-use versions on dark and white backgrounds.
Logo Files/PDF and EPS      - print/design compatibility exports; EPS opens in Illustrator.
Web Assets/Header           - optimized website header/portrait PNG sizes.
Web Assets/Favicon          - ICO plus 16/32/48/64 PNG favicons.
Web Assets/PWA              - standard and maskable PWA icon sizes plus manifest snippet.
Web Assets/Apple            - 180x180 Apple touch icon.
Web Assets/Social           - 1200x630 OpenGraph/social share graphic.
Source PNGs                 - the original supplied/generated transparent PNG artwork.

Brand colour
------------
Primary web blue: #00A4FF
Dark background:  #05080D

Important source note
---------------------
The supplied master artwork was raster PNG. The SVG/PDF/EPS files in this pack are clean
single-colour traces made from the artwork silhouette for practical web/print use; they are
not the original native Illustrator construction files. The original PNGs are included intact.
